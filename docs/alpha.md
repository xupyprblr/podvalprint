# Альфа 0.2.0: дизайн-система на сайте

## Что вошло

- Дизайн-система из `design/system` подключена к теме: токены и компоненты `pp-…` (`assets/css/pp/`),
  слой сайта `assets/css/pp-site.css`, иконки `assets/icons/`. Перенос новых версий — `scripts/sync-design.sh`.
- Шрифты Onest, Golos Text и Bitter раздаются темой (woff2, кириллица и латиница), без Google Fonts.
  Старые Oswald, Unbounded и Inter удалены; их имена в старых стилях указывают на новые шрифты.
- Новые шапка, мобильное меню и подвал (`header.php`, `footer.php`, `inc/design.php`).
- Новая главная `front-page.php` по макету `design/screens/Home.html`. Тексты — `inc/copy-data.php` → `home`,
  цены — из `inc/prices.php`, реквизиты — из `inc/brand.php`. Секция без данных не выводится.
- Внутренние страницы (каталог, товар, корзина, оформление, лендинги, конструктор) пока на старой вёрстке,
  перекрашенной в светлую тему через переменные. Их перевёрстка по макетам — следующий шаг.
- При активации темы создаются черновики служебных страниц со слагами из `routes`. Ссылки на страницу
  появляются в меню и подвале, когда её опубликуют.

## Установка на тестовый хостинг

1. WordPress → Плагины → Добавить → Загрузить: сначала WooCommerce, затем три плагина из архивов.
2. Внешний вид → Темы → Добавить → Загрузить тему: `podval-theme-<версия>.zip`, активировать.
3. Настройки → Постоянные ссылки: «Название записи».
4. На тестовом домене закрыть индексацию: в `wp-config.php` `define( 'WP_ENVIRONMENT_TYPE', 'staging' );`
   и галочка «Попросить поисковые системы не индексировать сайт» в Настройки → Чтение.
5. Валюта магазина: WooCommerce → Настройки → Основные → «Белорусский рубль».

Домен нигде не зашит: ссылки строятся от адреса сайта, поэтому при переезде на итоговый домен
достаточно сменить адрес в WordPress и заменить старый адрес в базе (например, `wp search-replace`).

## Меню и витрины

- Шапка: область «Основное меню» (Внешний вид → Меню). Пока она пустая, в шапке каталог с корневыми
  категориями и опубликованные служебные страницы. Вложенные пункты открываются выпадающим списком.
- Подвал: области «Футер — магазин» и «Футер — информация» заменяют первые две колонки.
- Главная: кнопки «Загрузить свой принт» и «Создать принт» ведут в категорию `custom-design`, а если её нет —
  в каталог. Блок шаблонов показывает товары категории `custom-design`, тёмный блок — категории `deadlock`.
- Фото первого экрана: theme_mod `podval_pp_hero_image` (ID вложения), иначе иллюстрация из макета.

## Как проверено

- `scripts/audit.sh` — 11 проверок, все проходят. Запускается в CI на каждый пуш.
- `php -l` для всех PHP-файлов и `node --check` для всех JS — без ошибок.
- Тестовый стенд WordPress 6.8.3 + WooCommerce 9.9.5 (SQLite): тема и три плагина активируются; главная, служебные страницы, лендинг, карточки товара и услуги, категории, корзина, поиск, 404 отдают 200 (404 — для 404) без ошибок PHP в `debug.log`.
- Сидер лендингов создаёт черновик из файла определения с верным шаблоном и title.
- В отрендеренном HTML этих страниц маркеров исходника нет; пути ассетов — только `/wp-content/themes/podval-theme/`.
- Ошибок JS в консоли на публичных страницах нет; набор совпадает с исходной темой на том же стенде.
- Тесты плагина Telegram-заказов: 277 проходят, 1 падает («память: гигантская отсекается»). Он так же падает на исходном коде в этом окружении, к переименованию не относится.

Не проверялось: оплата, СДЭК, вебхук Telegram и Mini App — им нужны боевые ключи. Чекаут с товаром в корзине вручную не проходился.

## Что остаётся похожим до редизайна

Переименование убирает прямые указатели, по которым исходник находится поиском. Сходство устройства страниц оно не убирает.

| Что | Почему осталось | Когда уходит |
|---|---|---|
| Вёрстка, CSS, порядок блоков, русские HTML-комментарии в разметке | Это и есть текущий дизайн | Неделя 3: новые шапка, подвал, главная, карточки |
| Классы без префикса темы: `sl-`, `sp-`, `aw-`, `chub-`, `tplb-`, `cd-`, `mnav_` и другие | На них завязаны JS и CSS; переименовывать вслепую рискованно | Вместе с вёрсткой соответствующего раздела |
| Логика и тексты интерфейса конструктора, загрузки макета, корзины, чекаута | Рабочий функционал | Тексты интерфейса — неделя 3–4; логика остаётся |
| Набор шаблонов принтов в `inc/print-templates.php` (названия, раскладки) | Это товарная линейка, решение за владельцем | Нужен свой набор шаблонов до запуска раздела |
| Цены по умолчанию в `inc/prices.php` | Нужны калькулятору | После решения о ценовой сетке |
| Слаги категорий и товаров в коде: `shop`, `custom-design`, `collections`, `uslugi`, `base` | На них около 190 ссылок в шаблонах | При сборке каталога и раздела коллекций |
| Файлы шрифтов, размерные сетки, логотипы платёжных систем, силуэты футболок | Типовые материалы | Шрифты и сетки — с новым дизайном |

## Что нужно заполнить

1. `inc/brand.php` — реквизиты и контакты (см. `docs/launch-checklist.md`). Пока они пустые, блоки с ними не выводятся.
2. `inc/copy-data.php` — тексты блоков: `product_info`, `product_seo`, `custom_hub`, `home_hero`, `bundles_seo`, `ticker`.
3. `inc/landings/` — определения лендингов первой волны.
4. Страницы в WordPress: о нас, доставка и оплата, гарантия и возврат, оферта, политика конфиденциальности.
5. Иконки Mini App и скриншот темы — заменить заглушки фирменными.

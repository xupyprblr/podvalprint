# Дизайн «Подвальный Принт»

Дизайн-система и макеты нового сайта. Папка на сайт не выкладывается — это источник для вёрстки темы.

| Папка | Что внутри | Как пользоваться |
|---|---|---|
| `system/` | Дизайн-система: `README.md` (правила бренда), `tokens.json`, `tokens.css`, `components/bundle.css`, описания и превью 39 компонентов, иконки и логотипы | Подключить `tokens.css` и `components/bundle.css`, писать разметку классами `pp-…` по `components/<Имя>/README.md` |
| `screens/` | 37 статичных HTML-экранов: главная, SEO-лендинг, изделие, конструктор во всех состояниях, шаблоны, корзина, оформление, Deadlock | Открыть `screens/index.html` через любой локальный сервер (`npx serve design`, `python3 -m http.server`) и брать разметку экрана как образец |
| `canvas/` | Исходники холста: `canvas.json` и `*.dc.html` по артборду, копия системы в `canvas/ds/pp/` | Править здесь или на холсте, затем пересобрать `screens/` |
| `tools/` | `render.mjs` и `dc-static.js` — сборка `screens/` из `canvas/` | `node design/tools/render.mjs` (нужен Playwright: `npm i -D playwright && npx playwright install chromium`) |

## Темы

Тема включается атрибутом `data-theme` на `<body>` или на секции:

- без атрибута или `light` — основная светлая (жёлтый акцент);
- `dark` — раздел Deadlock, «ночной путеводитель»: Bitter в заголовках, терракота и циан;
- `light-magenta`, `light-lime` — альтернативы акцента; после выбора удалить;
- `night` — предложение глобальной тёмной темы «Ночная смена». Есть только в `canvas/ds/pp/tokens.css`, в систему не внесена.

## Правила, которые легко нарушить

- Жёлтый `accent` — только заливкой с чёрным текстом, одна акцентная кнопка на экран.
- Шрифты: Onest (заголовки), Golos Text (текст), Bitter (только Deadlock). Шрифты старого сайта не используются. На продакшене woff2 раздавать со своего домена — сейчас в макетах подключён Google Fonts.
- Иконки — inline SVG из `system/assets/Icons` со `stroke="currentColor"`.
- Цены «00 Br», адрес, отзывы, текст о канале — заглушки. В теме цены идут через `[podval_price]`, реквизиты — через `podval_brand()`.
- В разделе Deadlock — никаких логотипов, артов и шрифтов игры.

## Откуда это

- Дизайн-система: артефакт «Подвальный Принт» (тип Design System) в claude.ai.
- Макеты: холст «Подвальный Принт — сайт» (тип Design) в claude.ai, страницы «Дизайн-система», «Главная, SEO, изделие», «Конструктор», «Шаблоны», «Корзина и заказ», «Deadlock».

Если меняете систему или холст в claude.ai, перенесите изменения сюда и пересоберите `screens/`.

# OrderStatus
Статус заказа шагами: принят → в печати → готов → выдан, с номером заказа.

**Что передаёт разработчик:** `.pp-orderno` с номером, бейдж текущего статуса и `<ol class="pp-track">` из четырёх `<li>` (пройденные — `is-done`, текущий — `aria-current="step"`) с названием `<b>` и датой.

**Правила:** текущий шаг — акцентная заливка в светлой теме, кольцо свечения в тёмной. Даты будущих шагов — «ожидается». Статус дублируется словом в бейдже.

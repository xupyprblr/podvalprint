# Tooltip
Короткая подсказка к иконке или термину — не больше одной фразы.

**Что передаёт разработчик:** элемент `.pp-tooltip[role=tooltip]`, связанный с триггером через `aria-describedby`; показывается по ховеру и фокусу, скрывается по Esc.

**Правила:** на тач-устройствах тултипов нет — важная информация должна быть в подписи. В панели действий конструктора тултип дублирует подпись и горячую клавишу.

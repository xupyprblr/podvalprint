# PriceTable
Таблица цен печати по форматам A7–A2 и тиражу.

**Что передаёт разработчик:** настоящую `<table class="pp-table">` с `<caption>` (условия скидок), `<th scope="col">`; числовые столбцы — `.is-num`; выделенная строка — `tr.is-hl`.

**Правила:** только HTML-таблица (не картинка, не div-сетка) — её индексирует поиск и читает скринридер. Размеры в сантиметрах с запятой: «29,7 × 42». На мобильном таблица прокручивается по горизонтали в обёртке с `overflow-x:auto`, первый столбец закреплён.

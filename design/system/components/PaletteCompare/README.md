# PaletteCompare
Сравнение трёх вариантов светлой палитры на одном примере: первый экран главной и секция с карточками.

**Что передаёт разработчик:** ничего — это витрина. Варианты включаются атрибутом `data-theme`: `light` (А, жёлтый), `light-magenta` (Б), `light-lime` (В). Меняются только `accent`, `accent-hover`, `accent-press`; поверхности, текст и статусы общие.

**Правило для всех трёх:** акцент — только заливка с чёрным текстом (`on-accent`): одна акцентная кнопка на экран, бейдж «Новинка», сигнальная полоса. После выбора варианта две другие темы удаляются из `tokens.json`.

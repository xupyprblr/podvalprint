# Logo
Три варианта словесного знака «Подвальный Принт» и короткой версии «ПП» — на белом и на чёрном, плюс иконка приложения.

**Что передаёт разработчик:** SVG из группы ассетов «Логотип» (`*-ink.svg` для светлых фонов, `*-paper.svg` для тёмных, `*-app-icon.svg` — жёлтая плитка). В шапке логотип вставляется inline с `fill="currentColor"` — тогда он сам берёт `ink` темы.

**Правила**
- Буквы нарисованы с нуля на квадратной сетке (штрих 22 из 100 высоты, фаски 45°), это не набор шрифтом — логотип не зависит от загрузки шрифтов.
- Охранное поле — высота буквы «П» с каждой стороны. Минимальная высота словесного знака — 24px, «ПП» — 16px.
- Цвета знака — только `ink` или белый; жёлтая плитка — только для иконки приложения и аватаров.
- В тёмной теме Deadlock — тот же знак, белым (`paper`); терракотой и цианом не красим.
- Не растягивать, не обводить, не добавлять тени и свечение.

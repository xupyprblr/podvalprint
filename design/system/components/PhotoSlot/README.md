# PhotoSlot
Слот для фото в шаблоне: пустой, загрузка, с фото, ошибка.

**Что передаёт разработчик:** `.pp-slot` с модификатором: `--empty` (кнопка, открывает выбор файла и принимает drag&drop), загрузка (`aria-busy` + `.pp-progress` с `--p` от 0 до 1), с фото (изображение + `.pp-slot__tools`: заменить, удалить), `--error` (`role="alert"`, причина и действие).

**Правила:** в ошибке — что не так и что делать («Файл 34 МБ · Максимум 20 МБ · Выбрать другой»). Прогресс анимируется `transform: scaleX`. Пропорция слота повторяет пропорцию места в макете.

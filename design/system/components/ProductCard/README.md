# ProductCard
Карточка изделия в каталоге печати: фото, название, мета (технология, ткань, плотность, размеры), цвета, цена «от» и кнопка.

**Что передаёт разработчик:** `<article class="pp-card">` → `.pp-card__media` (фото 4:5, фон `pp-tex-concrete` пока фото грузится) с `.pp-card__badges`; `.pp-card__body` с `<h3 class="pp-card__title"><a>` (ссылка растягивается на всю карточку), `.pp-card__meta`, `.pp-mini-dots`, `.pp-card__foot` с ценой и кнопкой.

**Правила:** фото — реальное изделие на бетонном фоне, без коллажей. Название — как ищут: «Футболка оверсайз». Мета — через «·». Карточка не завязана на футболку: для худи/шоппера меняются фото, мета и набор цветов. Кнопка в карточке — `secondary`; акцентная «В корзину» живёт на странице товара.

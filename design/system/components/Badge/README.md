# Badge
Короткая метка на карточке или в строке: «Новинка», «Лимит», «Ваше фото», «Ваш текст», статусы заказа, счётчик.

**Что передаёт разработчик:** `<span class="pp-badge pp-badge--{new|limit|outline|success|warning|danger|team-a|team-b|count}">`, при необходимости иконка `.pp-icon` перед текстом.

**Правила**
- «Новинка» — единственный бейдж в акцентном цвете. «Лимит» — инверсный (`ink`).
- «Ваше фото» / «Ваш текст» — обводка с иконкой: показывают, что шаблон персонализируется.
- Статусы всегда со словом и иконкой, не только цветом.
- `team-a` / `team-b` — только в тёмной теме и только парой («Жёлтая линия» и «Зелёная линия», как линии метро на карте) для двух коллекций.
- В тёмной теме для коллекционных меток есть ещё наклейка `.pp-sticker--s` (см. `Textures`).
- Не больше двух бейджей на карточке.

# Accordion
Аккордеон FAQ на нативных `<details>` / `<summary>` — работает без JS, ответы видны поисковику.

**Что передаёт разработчик:** `.pp-faq` с набором `<details><summary>Вопрос</summary><div class="pp-faq__a">Ответ</div></details>`; микроразметка `FAQPage`.

**Правила:** вопрос — так, как его ищут («Сколько стоит печать на футболке в Минске?»). Первый вопрос раскрыт. Ответ начинается с прямого ответа в одном предложении. Иконка «+» поворачивается на 45° (`transform`).

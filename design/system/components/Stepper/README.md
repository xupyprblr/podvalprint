# Stepper
Пошаговый индикатор «Шаг 2 из 4» с названиями шагов.

**Что передаёт разработчик:** `.pp-steps` с `--n` (число шагов), заголовком «Шаг N из M» и `<ol class="pp-steps__bar">`, где пройденные — `is-done`, текущий — `aria-current="step"`.

**Правила:** 3–5 шагов. Пройденные шаги кликабельны (возврат), будущие — нет. На мобильном подписи шагов скрываются, остаются «Шаг 2 из 4» и полоса.

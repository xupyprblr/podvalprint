# DeadlockCard
Карточка товара раздела Deadlock и мерча канала — только в тёмной теме: фото в кремовой рамке-открытке с жёсткой тенью, бейдж «линии» коллекции, наклейки-характеристики, название Bitter 800, цена и «В корзину».

**Что передаёт разработчик:** `.pp-card.pp-card--deco` внутри `[data-theme="dark"]`; фото принта на футболке; бейдж `pp-badge--team-a|b`; до трёх наклеек `.pp-sticker--s` (короткие прилагательные или «Лимит», «Тираж 50»).

**Правила:** карточка без фона и рамки — «открытка» лежит прямо на ночном фоне. При ховере рамка фото становится циановой (`glow`). Никаких логотипов игры, артов, героев и фирменных шрифтов — только своё фото принта и типографика системы.

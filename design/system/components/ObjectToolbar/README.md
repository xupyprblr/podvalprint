# ObjectToolbar
Панель действий над выделенным объектом: повернуть, масштаб, по центру, дублировать, выше, ниже, удалить, отменить, повторить.

**Что передаёт разработчик:** `.pp-objbar[role=toolbar]` с кнопками-иконками S (`aria-label` + тултип с горячей клавишей); разделитель `.pp-objbar__sep` перед историей; удаление — `.is-danger`.

**Правила:** панель появляется над объектом и не перекрывает его; на мобильном — закреплена над нижней панелью. Стрелки ←/→ переходят между кнопками (roving tabindex). Недоступное действие — `disabled`, не скрывается.

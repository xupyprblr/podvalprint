# Textures
Фактуры, разделители и технические метки — лёгкие, на CSS и крошечных SVG, без полноэкранных фото.

**Что передаёт разработчик:** классы на контейнере. Светлая: `.pp-tex-concrete` (бетон, SVG-шум ~400 байт), `.pp-hazard` (сигнальная разметка; в тёмной превращается в пунктир маршрута), `.pp-corners`, `.pp-regmark`, `.pp-dim`, `.pp-orderno`. Тёмная «ночной путеводитель»: `.pp-grain` (зерно поверх фона), `.pp-hl` (слово заголовка под терракотовым маркером), `.pp-sticker` / `--paper` / `--s` (наклейки-ярлыки с жёсткой тенью 6px и наклоном ±2°), `.pp-marker` (номер остановки в циановом круге), `.pp-route` / `--v` (пунктир маршрута), `.pp-frame` / `--tilt` (кремовая рамка-открытка 5px с жёсткой тенью), `.pp-note` (записка на бумаге с рваным краем), `.pp-torn-top` / `.pp-torn-bottom` (рваный край секции).

**Правила**
- Фактура — только фоном медиа и крупных плашек, никогда под основным текстом статьи.
- Сигнальная полоса — разделитель секций и низ первого экрана; не больше двух на страницу.
- Технические метки — декор с правдивыми данными: номер реального заказа, реальный формат.
- Мотивы путеводителя — только в тёмной теме. Наклон — не больше ±2°, одна-две наклонённые детали на экран.
- Подсветка `.pp-hl` — одно слово на заголовок.

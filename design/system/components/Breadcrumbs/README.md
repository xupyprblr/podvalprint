# Breadcrumbs
Хлебные крошки и пагинация — навигация, которая помогает и людям, и поисковику.

**Что передаёт разработчик:** `<nav aria-label="Хлебные крошки"><ol class="pp-crumbs">` со ссылками и последним пунктом `aria-current="page"`; пагинация — `<nav class="pp-pager">` с настоящими ссылками `?page=N` и `aria-current="page"` у текущей.

**Правила:** крошки на всех страницах, кроме главной, + микроразметка `BreadcrumbList`. Пагинация — ссылки, а не кнопки «Показать ещё» без URL. Каждая цифра — зона 44×44.

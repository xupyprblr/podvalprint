# SizeQuantity
Выбор размеров S–3XL с количеством по каждому — для заказов на компанию, команду, семью.

**Что передаёт разработчик:** `.pp-sizes` с ячейками `.pp-size` (название `.pp-size__name` + `.pp-stepper` с кнопками −/+ и `<output>`). Ячейка с количеством > 0 — `is-filled`; нет в наличии — `is-disabled`. Внизу — итог штук и цены.

**Правила:** кнопки степпера подписаны («Добавить M»), зона нажатия 44px. Ссылка на таблицу размеров — рядом с заголовком. Для худи и шопперов набор размеров приходит из данных (шоппер — «Один размер»), компонент не зашит под футболку.

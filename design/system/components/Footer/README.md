# Footer
Подвал сайта в обеих темах: логотип с одной фразой о мастерской, три колонки ссылок, юридическая строка.

**Что передаёт разработчик:** `<footer class="pp-footer">` (мобильный — `pp-footer--m`) с `.pp-footer__grid` и `.pp-footer__legal` (реквизиты ИП/ООО и УНП обязательны для белорусского магазина).

**Правила:** все ссылки — текстовые, без иконок-соцсетей без подписи. В светлой теме фон `surface`, в тёмной — `bg` с пунктиром маршрута сверху.

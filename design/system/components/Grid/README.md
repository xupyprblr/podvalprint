# Grid
Сетка макетов: 12 колонок на 1440, 4 колонки на 390.

**Что передаёт разработчик:** `.pp-container` (макс. ширина `grid-max` + поля) и `.pp-grid` (колонки и гаттер из токенов, на ≤600px переключается на мобильные значения).

**Правила:** вертикальный ритм секций — `space-9` (96px) на десктопе и `space-8` (64px) на мобильном. Карточки каталога: 4 в ряд на 1440 (по 3 колонки), 2 в ряд на 390. Промежуточная точка перелома — 1024px: 8 колонок, поля 32.

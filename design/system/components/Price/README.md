# Price
Цена: «от 00 Br», цена со скидкой, цена с разбивкой по позициям.

**Что передаёт разработчик:** `.pp-price` с числом и валютой «Br» через неразрывный пробел; `.pp-price__from` для «от», `.pp-price__old` (в `<s>` или с `aria-label="Старая цена"`) для зачёркнутой. Разбивка — `<dl class="pp-breakdown">`, итог — строка `.is-total`.

**Правила:** цифры всегда табличные (`tabular-nums`). Валюта — «Br» после числа. Скидку показываем бейджем `--new` с процентом рядом со старой ценой. Цена должна быть текстом в HTML (и в микроразметке `Offer`), не картинкой. В тёмной теме цена набирается Bitter 800.

# Button
Кнопки сайта: основная, акцентная «В корзину», вторичная, текстовая и только иконка — в размерах S, M, L.

**Что передаёт разработчик:** элемент `<button>` (или `<a>` для перехода) с классами `pp-btn pp-btn--{primary|accent|secondary|text|icon}` и при необходимости `pp-btn--s` / `pp-btn--l` / `pp-btn--block`. Иконка — inline SVG `.pp-icon` перед текстом. У кнопки-иконки обязателен `aria-label`.

**Состояния:** `:hover`, `:focus-visible`, `:active`, `disabled` / `aria-disabled="true"`, загрузка — класс `is-loading` + `aria-busy="true"` (текст остаётся в DOM для скринридера, визуально заменяется спиннером). Классы `is-hover`, `is-focus`, `is-active` — только для документации.

**Правила**
- Одна акцентная кнопка на экран — главное коммерческое действие: «В корзину», «Оформить», «Загрузить принт» на первом экране. Всё остальное — `primary` или `secondary`.
- `primary` (заливка `ink`) — завершающие действия форм и модалок. `secondary` — альтернатива рядом с акцентной.
- Текстовая — ссылки-действия внутри текста и «Все шаблоны» у заголовков секций.
- Высота M (44px) по умолчанию. L — первый экран и закреплённая нижняя панель. S — плотные панели, у неё невидимая зона нажатия 44px.
- В тёмной теме ховер добавляет `shadow-glow` — неоновый циановый контур; отдельно его не рисуем.
- Анимируются только `transform` и `opacity`; цвета меняются мгновенно.

**Не делать:** не ставить две акцентные кнопки рядом; не писать подпись капсом; не делать кнопку-пилюлю (`radius-full`).

# Chip
Чип-фильтр для каталога шаблонов и готовых футболок — переключатель с необязательным счётчиком.

**Что передаёт разработчик:** `<button class="pp-chip" aria-pressed="true|false">Текст <span class="pp-chip__count">N</span></button>`. Ряд чипов прокручивается по горизонтали на мобильном.

**Правила:** выбранный — заливка `ink`; несколько чипов могут быть выбраны одновременно. Для взаимоисключающего выбора используйте табы. Видимая высота 36px, зона нажатия 46px. Фильтры должны работать и без JS (ссылки с параметрами) — важно для индексации.

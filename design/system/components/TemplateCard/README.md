# TemplateCard
Карточка шаблона: пример макета, бейджи «Ваше фото» / «Ваш текст», название, короткое описание и «Создать макет».

**Что передаёт разработчик:** те же части, что у `ProductCard`, медиа квадратное (`pp-card__media--sq`), бейджи персонализации, кнопка `primary` «Создать макет».

**Правила:** описание отвечает на вопрос «что от меня нужно»: «Четыре буквы — четыре ваших фото». На примере макета — нейтральные фото с разрешением на использование.

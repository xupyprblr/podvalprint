# Tabs
Табы для переключения содержимого в пределах страницы: «Описание / Размеры / Уход».

**Что передаёт разработчик:** `.pp-tabs[role=tablist]` с `<button class="pp-tab" role="tab" aria-selected>`; панели с `role="tabpanel"`. Стрелки ←/→ переключают табы.

**Правила:** индикатор 3px — `ink` в светлой, терракота в тёмной. Всё содержимое табов должно быть в HTML страницы (скрыто, но не подгружено по клику) — поисковик должен его видеть. Для зон печати в конструкторе — отдельный компонент `PrintZoneTabs`.

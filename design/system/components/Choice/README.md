# Choice
Чекбокс, радио и переключатель на нативных `<input>` — со всеми состояниями.

**Что передаёт разработчик:** `<label class="pp-check"><input type="checkbox|radio">Текст</label>` или `<label class="pp-switch"><input type="checkbox" role="switch">Текст</label>`. Вся строка — зона нажатия ≥44px.

**Правила**
- Чекбокс — независимые опции и согласия. Радио — один из 2–5 вариантов; больше — `select` или свотчи. Переключатель — мгновенное действие без кнопки «Применить» (например, «Печать на рукаве» в конструкторе).
- Отмеченное состояние: заливка `ink` в светлой теме, `accent` (терракота) в тёмной — через `--pp-control-on`.
- Ошибка: `aria-invalid="true"` + текст `.pp-field__error` под группой.

# SummaryBar
Закреплённая нижняя панель конструктора и страницы товара: что заказано, итог и главная кнопка.

**Что передаёт разработчик:** `.pp-summary` (десктоп) или `.pp-summary.pp-summary--m` (мобильный) с `.pp-summary__info` (строка состава + цена), необязательным статусом и кнопками L. Позиция `position: sticky; bottom: 0` (`z-sticky`).

**Правила:** главная кнопка — акцентная «В корзину», одна. На мобильном — только состав коротко, цена и кнопка; учитывать `safe-area-inset-bottom`. Цена обновляется без сдвига макета (табличные цифры).

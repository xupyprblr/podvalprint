# EditorRail
Вертикальный рейл инструментов конструктора: иконка + подпись под ней.

**Что передаёт разработчик:** `<nav class="pp-rail">` с `<button class="pp-rail__item">` (иконка `.pp-icon` 24px + подпись); активный — `aria-current="true"`.

**Правила:** подпись всегда видна — без «угадай иконку». Порядок: Изделие, Загрузить, Текст, Шаблоны, Фигуры, Слои, Цвет. На мобильном рейл превращается в горизонтальную панель внизу над итогом с теми же пунктами.

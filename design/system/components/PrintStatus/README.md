# PrintStatus
Чип статуса «Всё в зоне печати» с версиями-предупреждениями и подпись размера принта: формат A7–A2 и сантиметры.

**Что передаёт разработчик:** `.pp-status` (+ `--warning` / `--danger`) с иконкой и текстом в `role="status"`; `.pp-printsize` с `<b>A3</b>` и размером; шкала форматов `.pp-formats` с `.is-on`; размерные линии `.pp-dim` / `.pp-dim--v`.

**Правила:** статус обновляется при каждом перемещении и объявляется скринридеру. Предупреждение не блокирует заказ, ошибка (мелкое фото) — блокирует кнопку «В корзину» с объяснением. Формат вычисляется по фактическому размеру принта и округляется до ближайшего большего.

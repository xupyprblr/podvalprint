# DarkTeaser
Тёмная полоса-секция внутри светлой страницы — тизер раздела Deadlock на главной.

**Что передаёт разработчик:** обычную `<section data-theme="dark">` внутри светлой страницы. Все компоненты внутри сами переключаются на тёмные токены и шрифт Bitter для заголовков.

**Правила**
- Полоса во всю ширину экрана, вертикальные отступы `space-9`. Сверху и снизу — рваный край `.pp-torn-top` / `.pp-torn-bottom`: страница путеводителя, вклеенная в светлую мастерскую.
- Внутри — фон `bg` с зерном `.pp-grain`, заголовок Bitter 800 с одним словом под маркером `.pp-hl`, пунктир маршрута с номерами остановок `.pp-marker`, одна терракотовая кнопка, записка `.pp-note`, 2–3 карточки `DeadlockCard`.
- Циан `glow` — только номера остановок и ховер.
- Никаких игровых логотипов, артов и героев.

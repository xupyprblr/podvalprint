# Header
Шапка сайта в обеих темах: десктоп с полным меню и мобильная с бургером и заметной корзиной.

**Что передаёт разработчик:** `<header class="pp-header">` (мобильная — `pp-header--m`) с логотипом `.pp-logo` (inline SVG, `fill: currentColor`), `<nav><ul class="pp-nav">`, инструментами: поиск, телефон, корзина `.pp-cart` со счётчиком. Мобильное меню — `.pp-mnav`.

**Меню:** Печать (Футболки, Оверсайз) · Шаблоны · Конструктор · Deadlock · Цены · Доставка · Контакты. Текущий раздел — `aria-current="page"` (подчёркивание 3px). «Печать» открывает `.pp-dropdown` по клику (`aria-expanded`), не по ховеру.

**Правила:** корзина — единственная акцентная кнопка в шапке, на мобильном всегда видна рядом с бургером. Телефон — ссылка `tel:`. Высота 72 / 56px. Меню — обычные ссылки в HTML (индексация). В разделе Deadlock шапка та же, тема меняется атрибутом `data-theme="dark"` на `<body>`.

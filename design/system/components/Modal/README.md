# Modal
Модальное окно для подтверждений и коротких форм на десктопе; на мобильном его заменяет `BottomSheet`.

**Что передаёт разработчик:** `<dialog>` или `.pp-modal[role=dialog][aria-modal=true]` поверх `.pp-scrim`, с заголовком (`aria-labelledby`), телом и подвалом с кнопками. Фокус уходит в окно и возвращается на триггер; Esc и клик по фону закрывают.

**Правила:** основная кнопка справа, отмена — `secondary` слева от неё. Ширина до 520px. Не открывать модалку поверх модалки.

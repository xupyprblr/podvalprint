# Toast
Всплывающее уведомление о результате действия: добавлено в корзину, предупреждение, ошибка.

**Что передаёт разработчик:** `.pp-toast` (+ `--warning` / `--danger`) с иконкой, заголовком `<b>`, текстом и необязательным действием. Контейнер тостов — `aria-live="polite"`; ошибки — `role="alert"`.

**Правила:** инверсный фон (`ink` / `on-ink`) отделяет тост от любой страницы; статус показывает иконка на soft-плашке. Успех исчезает через 4 с, предупреждение и ошибка — только по закрытию. Появление — `opacity` + `translateY`. Позиция: снизу по центру на мобильном (над нижней панелью), снизу справа на десктопе.

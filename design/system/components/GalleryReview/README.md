# GalleryReview
Карточка работы в галерее (фото, номер заказа, что напечатано) и карточка отзыва с источником.

**Что передаёт разработчик:** галерея — `.pp-card` с квадратным фото, `.pp-orderno` и подписью «тираж · зоны печати»; отзыв — `.pp-card.pp-review` с `.pp-stars` (`aria-label="Оценка N из 5"`), `<blockquote>`, именем, датой и ссылкой на источник.

**Правила:** только реальные работы и реальные отзывы со ссылкой на площадку (Яндекс Карты, Google, Instagram). Не выдумывать отзывы. Номер заказа — техническая метка, не обязателен.

# ShortAnswer
Блок «короткий ответ» — выделенный абзац с фактами в начале страницы: отвечает на запрос до прокрутки.

**Что передаёт разработчик:** `<aside class="pp-answer">` с бейджем-меткой «Коротко», одним абзацем-ответом и `<dl>` из 3–5 фактов (цена, срок, минимум, получение).

**Правила:** сразу под H1. Абзац — одно-два предложения с ключевой фразой страницы («печать на футболках в Минске»). Факты — проверяемые, цифрами. Один блок на страницу. Это текст в HTML, а не картинка или слайдер.

# PrintZoneTabs
Вкладки зон печати: Перед, Спина, Левый рукав, Правый рукав — с точкой-индикатором, если на зоне уже есть печать.

**Что передаёт разработчик:** `.pp-zones[role=tablist]` с `<button class="pp-zone" role="tab" aria-selected>`; при наличии печати — `<span class="pp-zone__dot" aria-label="есть печать">`.

**Правила:** набор зон приходит из изделия (у шоппера — «Сторона А / Сторона Б», у кепки — «Перед»). Точка не единственный сигнал: в итоге заказа зоны перечислены словами.

# ColorSwatch
Свотч цвета изделия: кружок ткани плюс текстовое название цвета — никогда не только кружок.

**Что передаёт разработчик:** `<fieldset class="pp-swatches">` с `<legend>` («Цвет: Чёрный») и `<label class="pp-swatch" style="--swatch:#hex"><input type="radio"><span class="pp-swatch__dot"></span>Название</label>`. `--swatch` — цвет ткани из каталога, не токен темы.

**Правила:** название цвета видно всегда (доступность и поиск: «чёрная футболка оверсайз»). Нет в наличии — `disabled`, пунктирная рамка, остаётся в ряду. Кружок с внутренней обводкой `line-strong`, чтобы белый был виден на белом.

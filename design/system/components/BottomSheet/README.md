# BottomSheet
Нижняя шторка для мобильного: выбор размеров, фильтры, действия — вместо модального окна.

**Что передаёт разработчик:** `.pp-sheet[role=dialog]` с `.pp-sheet__grab`, заголовком и содержимым; поверх `.pp-scrim`. Закрывается свайпом вниз, по фону и крестиком.

**Правила:** скругление `radius-lg` только сверху. Главная кнопка — внизу шторки на всю ширину, L. Высота — по содержимому, но не выше 90% экрана; внутри — прокрутка. Появление — `translateY`, при `prefers-reduced-motion` — без сдвига.

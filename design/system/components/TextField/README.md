# TextField
Поля ввода: текст, телефон с префиксом +375, textarea и select — с подписью, подсказкой и ошибкой.

**Что передаёт разработчик:** обёртку `.pp-field` с `<label class="pp-field__label" for>`, полем (`.pp-input`, `.pp-textarea`, `.pp-select > select` или `.pp-input-group` с `.pp-input-group__prefix`) и, по необходимости, `.pp-field__hint` / `.pp-field__error`.

**Правила**
- Подпись всегда над полем и всегда видна; плейсхолдер — только пример, а не подпись.
- Необязательные поля помечаем `<em>· необязательно</em>` в подписи; обязательные не помечаем звёздочкой.
- Ошибка: `aria-invalid="true"` на поле, текст ошибки в `.pp-field__error` со ссылкой через `aria-describedby`. Текст ошибки говорит, что сделать: «Введите 9 цифр номера после +375».
- Телефон: `type="tel"`, `inputmode="tel"`, `autocomplete="tel-national"`; префикс страны фиксированный.
- Размер шрифта в поле 16px — иначе iOS увеличивает страницу.
- Граница поля — `line-strong` (≥3:1); `line` для полей не используем.

Три варианта знака «Подвальный Принт»: `a-*` «Блок» (рекомендован), `b-*` «Трафарет», `c-*` «Уровень −1».

- `*-wordmark-ink.svg`, `*-mark-ink.svg` — заливка `#121212` (ink), для белого и светлых фонов (`bg`, `surface`).
- `*-wordmark-paper.svg`, `*-mark-paper.svg` — заливка `#FFFFFF`, для чёрного и тёмной темы Deadlock.
- `*-app-icon.svg` — «ПП» цветом ink на плитке `#FFD60A` (accent): фавикон, иконка приложения, аватары соцсетей.
- В шапке сайта знак вставляется inline с `fill="currentColor"` — так он берёт `ink` текущей темы.
- Минимальная высота: словесный знак 24px, «ПП» 16px. Охранное поле — высота буквы «П».

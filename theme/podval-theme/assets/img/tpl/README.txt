Превью основ для конструктора шаблонов (шаг 1 «Выберите основу»).

Имена файлов задаются в inc/print-templates.php → ключ 'preview'.
Сейчас ожидаются:

  dad-letters.jpg    — слово ПАПА из фото
  dad-poster.jpg     — BEST DAD постер с коллажем
  dad-single.jpg     — одно фото + имя
  dad-papa.jpg       — PAPA и 4 фото (группа «Папа / муж», с 3.7.11)
  polaroid-pair.jpg  — полароид (парные)

  Мама / жена (с 3.7.29, зеркало папиных основ):
  mom-letters.jpg    — слово МАМА из фото
  mom-poster.jpg     — BEST MOM постер с коллажем
  mom-single.jpg     — одно фото + имя
  mom-mama.jpg       — MAMA и фото

  Превью можно задать и в админке шаблонов (поле «Превью» основы).

Формат: JPG или WEBP, пропорция 3:4, рекомендуемый размер 600×800.
Лучше всего работают кадры с реальным человеком в футболке — по
референсам, а не плоские макеты на белом фоне.

Пока файла нет, карточка показывает буквенный плейсхолдер —
конструктор при этом полностью работоспособен.

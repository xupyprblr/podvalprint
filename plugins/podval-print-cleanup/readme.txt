Управление жизненным циклом клиентских файлов принтов: автоочистка, ручные операции, диагностика.

== Описание ==

Плагин управляет файлами, загруженными клиентами через страницу «Свой Дизайн» (хранятся в `wp-content/uploads/customer-prints/`):

* **Автоочистка по cron** — удаление файлов принта из заказов указанных статусов старше N дней
* **Чистка сирот** — attachment'ы, загруженные но не привязанные ни к одному заказу
* **Поиск файлов-призраков** — физически существуют на диске, но в БД нет записи
* **Предпросмотр** — видно что попадёт под чистку до удаления
* **Ручной запуск** — независимо от cron
* **История последних 20 запусков** со статистикой по файлам и байтам
* **HPOS-совместимость** (WooCommerce High-Performance Order Storage)

== Админ-панель ==

WooCommerce → 🗑 Очистка принтов

== Установка ==

1. Загрузить ZIP через Plugins → Add New → Upload Plugin
2. Активировать
3. При активации настройки автоматически мигрируют из Customizer → Podval Print → Очистка файлов (если были)
4. Зайти в WooCommerce → Очистка принтов, проверить настройки

После активации плагина можно смело обновлять тему podval-theme до прежней версии (старый код очистки в теме удалён).
